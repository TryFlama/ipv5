# 🌐 TryFlama IPv5 (5-Octet Decimal Protocol)

![License](https://img.shields.io/badge/License-BSL%201.1%20Permanent-blue?style=for-the-badge)
![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20Linux-green?style=for-the-badge)

**TryFlama IPv5** es una capa de red alternativa y simplificada diseñada para superar las limitaciones de agotamiento de direcciones de IPv4 sin la complejidad innecesaria del direccionamiento hexadecimal de IPv6. 

Al expandir el espacio de direccionamiento decimal a **5 octetos** (ejemplo: `192.192.192.192.192`), TryFlama IPv5 ofrece un direccionamiento masivo, intuitivo y legible para humanos, respaldado por un sistema de despliegue automatizado y tunelizacion centralizada.

---

## ⚡ Características Principales

* **Direccionamiento Decimal Extendido:** Adióse al hexadecimal. 5 bloques octetales simplificados.
* **Despliegue en 1-Clic:** Scripts automatizados (`.bat` para Windows / `.sh` para Linux) que configuran la interfaz, certificados y túneles en segundos.
* **Integración DNS Nativa via CNAME:** Compatible con la infraestructura web existente mediante resolución CNAME (`[tu-ip].tryflama.com`).
* **Soporte HTTPS Auténtico:** Inyección automatizada de certificados raíz de confianza en el almacén del sistema para navegación sin advertencias de seguridad.
* **Infraestructura Centralizada:** Enrutamiento de alto rendimiento procesado directamente desde la red central de nodos de TryFlama.
